## 五、下一步建议（按性价比）

1. **音效**（打字音 / 呼噜 / 喂食「喵」）——最容易提升「生命感」，用 `PlaySound` + 内嵌 WAV，约 +30KB
2. **多屏穿梭**：漫步目标点扩展到所有显示器
3. **猫画风设置面板**：半透明卡片 + 滑块，替代菜单
4. **重力下落**：松手后按 y 速度下落到工作区底部，带反弹
