# 后颈拖拽物理（2D 摆动）

> 抓猫后颈把它提起来 → 身体像钟摆一样左右荡、上下沉浮，尾巴慢一拍甩，松手有软弹落地。
> 实现对齐上游 v1.4.3 的 2D 拖拽手感思路，但代码是我们自己的（C++17，零依赖）。

## 1. 抓取判定

- 鼠标按在小猫的**后颈区域**（头部下方的颈背）并拖动 → 进入 `isScruffDragging_` 状态。
- 拖动期间每帧把鼠标位移量累加（水平 + 垂直），交由弹簧系统平滑。
- 松手触发 0.16s 的落地缓冲窗口，身体给一个软弹（`bodySquash.velocity -= 1.8f`）。

## 2. 四个弹簧（决定手感）

| 弹簧 | 作用 | 刚度 / 阻尼 | 目标值 |
|---|---|---|---|
| `scruffDrag` | 悬空程度（0=坐地，1=完全吊起） | 190 / 17 | 拖拽时 1.0 |
| `scruffSwing` | 水平摆动 | 92 / 7.4 | `0.92·tanh(dx/18)` |
| `scruffSwingY` | 垂直沉浮 | 108 / 8.4 | `0.78·tanh(-dy/18)` |
| `scruffTailSwing` | 尾巴滞后摆 | 58 / 5.2 | `1.22·tanh(dx/16)` |

速度估计用了「本帧累计位移 × 时间缩放 + 指数平滑」：

```cpp
instDx = accumX * (dt * 60);
dragDx = dragDx * 0.52f + instDx * 0.85f;   // 松手后按 0.80 衰减
```

## 2b. 对齐作者实现的四项关键差异（第二轮补）

第一版只把「坐姿的猫」整体上移，作者做的是**专门的悬空姿态**。这次补齐了 4 项：

| # | 项 | 做法 | 效果 |
|---|---|---|---|
| 1 | **桌面淡出** | 鼠标与键盘渲染到离屏位图，按 `1 - smoothstep(0, 0.48, scruffS)` 的 alpha 合成回主画布 | 拎起来时桌子消失，「离开桌面」的观感 |
| 2 | **四爪下垂** | 爪子目标改到 `liftSeatY + 24`（`liftSeatY = Seat - scruffS*44`），左右各带 24px 摆动 + 2.2px 呼吸 bob | 四肢自然垂着晃，不再像坐着 |
| 3 | **尾巴无力下垂** | `tailCurve` 增加 droop 分支：根部向下 76px 的贝塞尔，tip 随摆动横向 26px | 被拎着的猫尾巴垂下来 |
| 4 | **落地软弹** | 松手时 `bodySquash.velocity -= 2.4`、`headOffsetY.velocity += 78` | 落地那一瞬头部轻弹、身体压扁回弹 |

起吊高度也从 38px 提到 **44px**（与作者一致）。

### 实测验证（桌面淡出）

| 状态 | 键盘区亮像素（y 240–312） |
|---|---|
| 悬空 | **0** |
| 落地 | 6809 / 6834 / 6666 / 6837 |

说明键盘在悬空时确实完全淡出，不是「看起来淡」。

### 仍缺（作者有、我们暂未实现）

1. 拱背悬空专属轮廓（作者 `drawNativeScruffDragCat`，约 400 行专门姿态）
2. startle 面部（被拎起瞬间瞪眼 + 额外高光点）
3. 桌面物件随拎起下移 28px 的过渡动画

## 2c. 第三轮：向作者姿态再靠一步

| # | 项 | 做法 | 实测 |
|---|---|---|---|
| 1 | **startle 瞪眼** | 物理新增 `scruffStartle`：刚抓起 0.14s 内 = 1，之后 0.08s 衰减；落地后 0.16s 反向。悬空时瞳孔放大到 `1.10 + 0.18·startle` | 被抓瞬间眼睛明显变大 |
| 2 | **悬空拉伸 + 随摆动剪切** | 悬空 2% 以上时对整体做 `Scale(1-0.03·S, 1+0.10·S)` + `Rotate(摆动·3.5°)`，以座位为锚点 | 身体纵向高度 193→245px（**拉长 52px**） |
| 3 | **桌面下沉** | 淡出同时把鼠标/键盘下沉 `scruffS·28px`，与作者一致 | 键盘区亮像素：悬空 **0** vs 落地 **6853** |

## 2d. 与作者仍有差距的部分

作者有 400 行的 `drawNativeScruffDragCat`：**重新绘制**一条从颈背到臀的拱形轮廓（分段贝塞尔 + startle 上浮），四肢是独立的悬挂 IK。
我们目前是「坐姿剪影 + 拉伸/剪切」近似，观感已经接近但轮廓细节不如作者：

- 拱背的弧度（我们是整体拉伸，不是重画轮廓）
- 四条腿独立摆动相位（我们只有前后两组）
- 耳朵在悬空时的折耳角度

若要完全对齐，需要单独一轮重写悬空姿态渲染（约 300–400 行），建议先在对比图确认方向。

## 2e. 第四轮：直接移植作者的专用姿态（不再用拉伸近似）

第三轮之前我们用的是「坐姿剪影 + 拉伸/剪切」，观感生硬。这一轮**整段移植**了作者 v1.4.3 的 `drawNativeScruffDragCat`（499 行）：

| 组成部分 | 移植内容 |
|---|---|
| 拱背轮廓 | 颈背 → 肩峰（scruffPeak）→ 臀 → 腹 → 胸 → 颈前的 6 段贝塞尔闭合路径 |
| 四条垂爪 | `DragLimb` + `makeLimb` / `buildLimbPaths` / `drawDragLimb`：从身体深锚点伸出的弯曲小腿，随拖动方向拖尾 |
| 垂尾 | `evalTailPt` 采样贝塞尔 + 分段描边 + 环纹，随摆动甩 |
| 头部 | 复用作者的 2.5D 头部投影（`headPoint(..., whiteSurface)`）+ 白面罩/milk mark 处理 |
| 装饰 | 锚点改为悬空时的颈部/尾尖位置 |

配套移植的辅助函数（6 个）：`fillClampedLinearGradient`、`isClassicBlackRim`、`whiteOutlineEnabled`、`isMilkMark`、`lerpF`、`lerpPt`、`setRound`、以及 `smoothstepf`。

### 渲染路径

```cpp
// CatRenderer::draw()
if (scruff > 0.02f) {
    drawNativeScruffDragCat(g, physics, skin, settings.eyeTheme, scruff);
    g.Restore(flipState);
    return;
}
```

也就是说：**悬空时完全不画坐姿那套**（不画尾巴/剪影/前爪/贴纸），只画作者这套专用姿态。地面上则完全走原来的渲染。

## 3. 渲染表现

| 部位 | 表现 |
|---|---|
| 身体 | 起吊高度用 smoothstep：`seatY -= scruffS * 38`（避免线性生硬的「电梯感」） |
| 头部 | 随悬空上提 20px，并叠加水平摆动 16px |
| 前爪 | 悬空时收拢并随摆动轻晃（含垂直分量） |
| 尾巴 | 绕尾根旋转 ±9°，直接旋转贝塞尔控制点（不泄漏 Graphics 状态） |
| 装饰贴纸 | 尾尖锚点跟随摆动的尾巴（避免贴纸与尾巴分离） |

## 5. 可调参数（想改手感改这四个）

```cpp
// windows/src/CatPhysics.hpp
scruffSwing.target  = 0.92f * std::tanh(scruffDragDx_ / 18.0f);  // 摆幅
scruffSwingY.target = 0.78f * std::tanh(-scruffDragDy_ / 18.0f); // 沉浮
scruffTailSwing.step(dt, 58.0f, 5.2f);                           // 尾巴更软
seatY -= scruffS * 38.0f;                                       // 起吊高度
```

## 6. 与上游实现的差别

| 项 | 上游 v1.4.3 | 本实现 |
|---|---|---|
| 结构 | 同时改造渲染器（+3507 行，含 Douni 手臂等） | **只改物理 + 4 处渲染偏移**，不动其他绘制 |
| 手感公式 | 同源（tanh 映射） | 保持一致，便于对照 |
| 尾巴 | 渲染器内整体摆动 | 旋转贝塞尔控制点，状态安全、无残留变换 |
