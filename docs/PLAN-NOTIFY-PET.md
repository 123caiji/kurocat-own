# 方向 F：消息提醒桌宠（规划）

> 想法：Tama 不只是「看键盘」，而是**替你盯着该注意的事**——消息、提醒、任务、状态，用猫的动作表达出来。

## 1. 差异化定位

| 现状 | 竞品 | 我们的位置 |
|---|---|---|
| 桌宠只会卖萌 | BongoCat / VPet | 猫是「注意力代理」 |
| 键显工具只会显示按键 | keyviz / KeyCastOW | 猫同时显示「你」和「系统」 |
| AI 助手只会弹通知 | 各类 agent 工具 | 通知由猫演出，不打断 |

一句话：**把「消息/提醒」翻译成猫的行为**。别人发消息 → 猫扯你袖子；任务完成 → 猫竖尾巴；出错 → 猫垂耳。

## 2. 三层功能（按阶段）

### 第 1 层：本地提醒（1 周，零依赖）

| 功能 | 触发 | 猫的表现 |
|---|---|---|
| 番茄钟 / 久坐提醒 | 计时器，45/60 分钟 | 猫站起来伸懒腰 + 气泡「该休息了」 |
| 喝水提醒 | 间隔 40 分钟 | 猫舔爪 + 气泡「喝口水」 |
| 定时提醒 | 用户设定（如 18:00 下班） | 猫竖尾 + 气泡 |
| 免打扰 | 专注模式 | 所有气泡静默，只闪一下耳朵 |

实现：Win32 定时器 + 现有 keycap/气泡系统，**不联网**。

### 第 2 层：系统通知聚合（2 周，需决定隐私边界）

| 功能 | 技术 | 风险 |
|---|---|---|
| 监听 Windows 通知 | UIA / 通知监听（第三方库或 WinRT） | **会读到其他应用内容，需用户明确开启** |
| 托盘气泡 / 应用角标 | `Shell_NotifyIcon` + 窗口标题扫描 | 低 |
| 消息计数角标 | 扫描任务栏按钮 | 低 |

> 红线：**默认关闭**；只上报「有几个未读」，不记录内容；不落盘。

### 第 3 层：外部消息源（3 周，可选）

| 功能 | 技术 | 说明 |
|---|---|---|
| DSH / Agent 状态 | 已有 `state.json` 桥 | 已完成 |
| 任意脚本/程序 | 写 `notify.json`（本地文件） | 通用、零依赖 |
| 本地 HTTP Webhook | `POST localhost:7321/notify` | 供浏览器插件/CI 用 |
| 邮件 / IM | 不直连；由脚本转发到本地文件 | 避免账号凭据进入客户端 |

## 3. 交互设计（关键：不打扰）

| 场景 | 表现 |
|---|---|
| 有 1 条新消息 | 猫耳朵动一下 + 尾巴尖抖动（3 秒） |
| 有 3+ 条 | 猫扭头看你 + 竖尾 |
| 任务完成 | 猫伸懒腰 + 小撒花 |
| 出错 | 猫垂耳 1.5 秒 |
| 免打扰时段 | 完全不动，只在托盘显示角标 |

**原则**：默认不弹窗、不发声音、不抢焦点。

## 4. 技术选型建议

| 项 | 建议 | 理由 |
|---|---|---|
| 通知源 | 文件 + 本地 HTTP 双通道 | 前者零依赖，后者方便第三方 |
| 调度 | 一个 150ms 轮询线程（复用现有） | 不引入新依赖 |
| 表现层 | 复用现有键帽气泡 + 新增姿态 | 不重写渲染 |
| 隐私 | 默认全关，逐项开关 | 与我们既有隐私红线一致 |

## 5. 验收线

| 指标 | 红线 |
|---|---|
| 提醒延迟 | ≤ 200 ms |
| 额外内存 | ≤ 3 MB |
| 额外 CPU（空闲） | ≤ 0.3% |
| 误报 | 免打扰时段 0 次打扰 |
| 隐私 | 不记录通知内容、不联网 |
