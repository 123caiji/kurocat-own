## 2. 值得注意的三件事

1. **上游也把悬空拖拽回滚了**（v1.5.3 最新提交）——说明我们前几天“越改越怪”的体验，作者自己也不满意，最终回到旧动画。
2. **设置 UI 改成「纯白 3 页签」**（macOS/Windows/Linux 统一）——正好是我们做失败又撤掉的那块，作者给出了最终形态，可以作为参考。
3. **皮肤格式升到 formatVersion 2** 并引入 `shared/rig.json` 骨骼定义，同时 `InputEngine` 增加约 400 行（输入层大改）。

## 3. 我们可以挑着移植的点（按性价比）

| 项 | 价值 | 风险 | 建议 |
|---|---|---|---|
| 纯白 3 页签设置 UI | 解决“设置难看” | 低（独立窗口） | **先看作者的布局再决定**，不要自己硬编 |
| 性能大改（v1.5.0） | 降低 CPU/内存 | 中（渲染器重构） | 只挑「空闲/跑马灯/睡眠降帧」这类单点 |
| 皮肤 formatVersion 2 + rig.json | 生态兼容性 | 高（解析器+渲染器） | 暂不追，等我们明确要接社区皮肤再说 |
| 听音乐戴耳机 | 有趣、传播性强 | 中（需要音频会话检测） | P2 趣味项 |
| MCP Server | 让 AI 能控制猫 | 低（独立进程） | 与「消息提醒桌宠」组合有想象力 |
